# Scripts to generate plots published in Tonnelé et al. 2026

in `data/`: results from analysis and used to plot

in `nf-params/`:

- `realdata`: params files used to submit pipeline [nf-realdata](https://github.com/Baud-lab/CoreQuantGen/tree/Master/nf-realdata) 
- `simulations`: params files used to submit pipeline [nf-simulations](https://github.com/Baud-lab/CoreQuantGen/tree/Master/nf-simulations) 
- `simvc`: starting parameters for simulations, to copy into `nf-simulations/input/vc` to run

in `Rfun/`: custom functions used in R scripts

in `plot/`: plots (pdf) used to mount figures in Adobe Illustrator
